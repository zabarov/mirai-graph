# Mirai 2.3 Organization Corpus

Status: synthetic conformance corpus for `2.3.0-alpha.1`.

`bundle.json` binds a bounded organization graph, cluster proposals, task
execution records, public projections and the Program 1.1 operation catalog.
It is consumed by both the TypeScript reference implementation and the
independent Python checker.

The corpus contains no production data or authority. Recorded approvals and
acceptance are synthetic evidence for conformance tests only.
