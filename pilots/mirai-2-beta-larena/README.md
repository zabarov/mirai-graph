# Mirai 2 Larena Beta Pilot

Status: governed sandbox engineering evidence; comparative review pending

This pilot reuses a frozen bounded task whose historical blind benchmark did
not promote any of the prompt, package-extractor or Mirai Graph 1.4 conditions.
The Mirai 2 condition writes exactly two allowed files in a disposable worktree
and runs three host-allowlisted checks.

The public Program accepts source text as runtime input. Source text, the raw
episode, sandbox path, capability grants and approval receipt remain host-local.
Only digest-bound IR, replay verdict and sanitized evidence are published.

This is evidence that governed execution can complete the bounded task. It is
not a randomized or blinded comparison with the historical benchmark.
