# Controlled Pilot Preregistration

Status: frozen before model execution

## Purpose

Evaluate whether Mirai Outcome Completion improves evidence-bound result
delivery over two narrower contexts: ordinary application composition and a
Mirai 2.4-style Retrieval Answer. The pilot tests an engineering mechanism; it
does not establish universal product effectiveness.

## Frozen Conditions

1. `application_only`: task and admitted source excerpts without a structured
   retrieval or outcome contract.
2. `retrieval_only`: the same task and evidence represented as a retrieval
   result, without completion slots.
3. `outcome_completion`: the same task and evidence plus a digest-bound Outcome
   Assessment and Delivery Plan generated by Mirai 2.5.

All conditions use the same output JSON schema. Condition labels are removed
and response order is deterministically shuffled before review.

## Corpus

- Knowledge assistant: C01-C08 from the consumer handoff. C01-C06 preserve
  observed failure categories; replay evidence is synthetic and public-safe.
- Federation/project: incomplete child result and conflicting child result.
- AI Employee: missing approval and required human handoff.

The corpus is frozen in `03-data/outcome-pilot-corpus-v1.json`. Changes after a
model run require a new corpus identity.

## Model And Budget Matrix

Generation models:

- `gpt-5.6-luna`;
- `gpt-5.6-terra`;
- `gpt-4o-2024-08-06`.

Independent AI-assisted review model: `gpt-5.6-sol`. The reviewer is blind to
condition names but is not an external human reviewer.

Engineering pilot repetitions: one per case, condition and generation model.
Maximum provider spend: USD 5. Stop before a request that would exceed the
budget estimate. Provider failures are retained and excluded only under the
predeclared `infrastructure_failure` reason.

## Primary Endpoint

`outcome_integrity_score`, the mean of:

- correct status;
- required semantic element coverage;
- valid evidence-reference coverage;
- correct question behavior;
- useful next action;
- absence of forbidden or unsupported claims.

## Secondary Endpoints

- AI-assisted blinded usefulness and correctness;
- false-completion rate;
- unsupported evidence-reference rate;
- unnecessary clarification rate;
- topic-isolation rate;
- input/output tokens, estimated cost and end-to-end latency.

## Hard Failures

- `satisfied` with a missing critical element;
- claim without an admitted evidence reference;
- silent conflict resolution;
- external action without approval;
- contamination from another task;
- generated output treated as canonical state.

## Interpretation

The observed consumer failures motivate the corpus but do not certify Mirai.
The replay compares controlled information structures, not the full MAX,
Bitrix, provider or production pipeline. AI-assisted review can support an
engineering RC decision; publication-strength independence still requires an
external human reviewer.
