# Mirai 2 AI Employee Beta Pilot

Status: dry-run engineering evidence; production and comparative review blocked

This program executes a public-safe AI employee workflow:

```text
request -> intent -> governed context -> character boundary -> decision
-> draft -> simulation approval -> simulated action -> feedback -> lesson proposal
```

It has no adapter effects. The approval value authorizes only a pure simulation;
it is not a capability grant and cannot authorize provider, send, write or
canonical-learning actions.
