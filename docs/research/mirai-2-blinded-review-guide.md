# Mirai 2 Blinded Review Guide

Status: preregistration candidate

An outcome reviewer receives the frozen task, allowed source material, produced
artifact and domain rubric. The packet omits `condition_id`, `model_class`,
runtime name, prompt transcript and internal route labels. A separate custodian
keeps the mapping until the scoring file is locked.

The reviewer records task correctness, missing mandatory outcomes, material
defects, accepted/blocked verdict and a concise rationale. Runtime conformance,
authorization and receipt integrity remain machine-scored and are not inferred
from artifact quality.

One author cannot count a self-review as independent. Review evidence must
identify a pseudonymous reviewer, rubric version, artifact digest and review
time without publishing personal data or hidden condition labels.

Unblinding occurs only after all planned reviews for the analysis batch are
locked. Corrections after unblinding are retained as new records rather than
silently replacing the original score.
