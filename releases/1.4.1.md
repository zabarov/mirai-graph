# Mirai Graph 1.4.1

Mirai Graph 1.4.1 is the frozen maintenance and compatibility baseline for the
Mirai 2.0 development track.

It aligns public documentation with the 1.4 release, pins supported Node.js
versions and documents independent product, manifest and extension contract
versions.

No graph semantics, validator behavior, CLI command or Project Technology
runtime behavior changes in this release.

Validation:

```bash
npm run release:check
npm pack --dry-run --json
```

Important boundaries:

- the product/package version is `1.4.1`;
- the existing `graph.json` manifest contract remains `2.0.0`;
- the Project Technology activation contract remains `1.0.0`;
- this release does not claim Mirai 2.0 runtime functionality.
