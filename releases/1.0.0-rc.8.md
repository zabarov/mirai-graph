# Mirai Graph 1.0.0-rc.8

This release candidate introduces one public Project Technology mechanism for
projects, skills, platforms and federations while preserving their separate
domain graphs and Hybrid Source Of Truth boundaries.

## Verified outcome

- one `graph.json` manifest and one `mirai.project_technology` extension;
- task-scoped context and safe tracked-file inventory;
- complete target provider export and consumer binding;
- forward-only, idempotent refresh-binding;
- read-only diagnostics alongside fail-closed significant work;
- no private source or full graph copied into bounded exports.

Stable `1.0.0` remains deferred until this RC has been exercised by the SIMAI
Federation and all release-managed skills.
