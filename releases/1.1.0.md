# Mirai Graph 1.1.0

Mirai Graph 1.1.0 adds universal, sequential context traversal to the existing
Project Technology mechanism.

## What changed

- A caller can discover top-level candidates, expand selected branches to any
  depth, compile the mandatory closure and verify actual use.
- The same protocol is available through the CLI and JavaScript API.
- Required processes, constraints and validators are included independently of
  a model's selection.
- Context packs are deterministic, revision-bound and safe to transfer without
  copying private source content.

## What was validated

- Software, research, organization, platform, skill-like and
  multi-repository fixtures.
- Sequential and batched expansion equivalence.
- Fail-closed behavior for incomplete, stale, blocked, deprecated, conflicting,
  cyclic, tampered and over-budget context.
- Zero-write read-only behavior and compatibility with the existing Project
  Technology provider/consumer contract.
- A dedicated traversal job on macOS, Linux and Windows.

## Compatibility

`graph.json` remains schema `2.0.0`; the Project Technology activation contract
remains `1.0.0`; existing graphs do not require migration.

## Claim boundary

The release proves deterministic contract behavior on the maintained fixtures.
It does not claim that automatic ranking alone understands every domain or that
a generated context pack authorizes changes.
