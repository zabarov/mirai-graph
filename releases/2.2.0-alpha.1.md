# Mirai 2.2.0-alpha.1

Status: local development release preparation; not tagged or published

## Summary

Mirai 2.2 introduces the **Autonomic Fabric**, an opt-in, governed loop for
connecting heterogeneous sources, organizing provenance-bound knowledge,
discovering process candidates and applying only reversible adaptive changes
that fit a host-authorized autonomy envelope.

It extends Mirai 2.1. Program `1.0.0`, Runtime `1.0.0`, Project Capsule and the
`mirai-graph` compatibility surface remain supported.

## Added

- Source/Converter SDK with deterministic snapshots and diffs.
- Read-only Files, Git, HTTP, PostgreSQL, MySQL and S3-compatible providers.
- Text, Markdown, JSON, YAML, CSV, HTML, PDF, DOCX and XLSX normalization.
- Assertion quality vectors, identity and alias resolution, conflicts,
  provenance, freshness and non-destructive lifecycle transitions.
- Separate intended and observed process observations, process candidates and
  proposal-only technology drafts.
- Trust strata, autonomy envelopes, host-local authorization receipts,
  evolution decisions, CAS promotion receipts and rollback.
- A bounded, deterministic `mirai autonomic reconcile --once` operation.
- Schemas, positive and negative fixtures, four synthetic pilots and local
  independent Python conformance results.

## Safety Boundary

- Source content is data; it cannot issue instructions, approvals or
  capabilities.
- Connectors are read-only. External writes remain Mirai Runtime effects.
- Conflicts, ambiguous identity, authority, protected state and effectful
  technologies cannot auto-promote.
- The autonomy envelope cannot modify or authorize itself.
- Generated knowledge, Programs, evidence and receipts do not become canonical
  owner truth automatically.


## Limitations

- The independent checker changes are local and have not passed public CI.
- Connector integration tests against real governed services are pending.
- Current pilots are synthetic and have not received independent human review.
- Cross-platform clean-room installation and a dedicated security review for
  converters/connectors/autonomy are pending.
- Scientific protocols are prepared, but confirmatory results do not exist.
- This alpha is not a production-write authorization or a stable release.
