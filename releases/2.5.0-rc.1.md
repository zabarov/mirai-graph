# Mirai 2.5.0-rc.1

Status: release-candidate engineering freeze; tag, GitHub Release and npm publication not performed

Mirai 2.5 adds Outcome Completion as an additive core extension. It checks
whether the requested useful result is supported by required evidence without
creating a second runtime or treating retrieval output as business acceptance.

## Candidate Surface

- `@zabarov/mirai/outcome` for CommonJS and ESM;
- four versioned Outcome Completion contracts;
- deterministic assessment and delivery planning;
- pure Outcome operations composed through existing Mirai Program nodes;
- additive Task Plan bindings;
- validation, explanation and proposal-only CLI commands;
- knowledge assistant, Federation/project and AI Employee shadow fixtures;
- independent Python checker implementation.

## Current Evidence

- all local Outcome tests, negative fixtures and CLI checks pass;
- packed CommonJS and ESM consumers load the Outcome export;
- the independent Python checker passes 32 tests locally and on Linux, macOS
  and Windows, with one optional organization bundle skipped locally;
- the frozen public-safe controlled pilot completed 108 generation runs and 36
  condition-blind AI review groups with zero provider failures at USD 0.7510;
- Outcome Completion reached 1.000 exact-status accuracy and 0.931 outcome
  integrity on this corpus, while five of 36 runs still failed the strict
  evidence-reference hard check;
- the isolated AI-assisted security review found five reproducible false-green
  classes; all were fixed and regression-tested. The review is not an external
  human audit.

## Release Boundary

- the package is an RC, not the stable `latest` release;
- tag, GitHub Release and npm publication require a separate live release
  approval;
- product-specific production-write authority remains outside this candidate;
- external blinded human review remains a future scientific strengthening
  step, not a claim made by this RC.

No Outcome contract grants approval, capability, execution authority or a
canonical write. Production effects remain outside this candidate.
