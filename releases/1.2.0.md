# Mirai Graph 1.2.0

Mirai Graph 1.2.0 adds portable project continuity to the existing Project
Technology mechanism.

Verified outcomes, requirements, evidence and reusable cases can now be stored
in `graph/specs` and discovered automatically by a later task. The mechanism
does not store chat transcripts and does not introduce a second memory database.

Mutable receipts and rollback data remain on the current host. Git repositories
and ordinary shared folders use the same canonical graph contract; shared-folder
writes additionally use a lease and compare-and-swap digest.

Goals, architectural decisions and owner or source-of-truth changes remain
proposals until explicitly accepted. A generated context document remains a
readable projection rather than a source of truth or write authorization.

`graph.json` remains schema `2.0.0` and
`mirai.project_technology.contract_version` remains `1.0.0`.
