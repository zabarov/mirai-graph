# Mirai 2.0.0-alpha.1

Release type: development alpha

## Summary

This release introduces the typed Mirai Program contract and deterministic
compiler while preserving Mirai Graph Core and the 1.4 Hybrid SOT model.
Alpha.1 validates and compiles process definitions but does not execute
effects.

## Added

- `@zabarov/mirai` package identity and `mirai` primary CLI;
- `mirai-graph` and `mirai_graph` CLI compatibility aliases;
- ESM and CommonJS subpath exports for core, program, runtime, adapters and
  conformance;
- `.mirai.yaml` authoring and canonical `.mirai.json` IR;
- safe expression AST, typed slots, bounded control nodes and effect
  declarations;
- deterministic semantic digest and diagnostic source map;
- static validation and plan simulation;
- proposal-only migration from explicitly bound 1.4 executable technologies;
- positive and negative conformance fixtures.

## Validation

```bash
npm run build
npm run test:mirai-alpha1
npm run validate:mirai-program
npm run test:mirai-program-negative
npm run release:check
```

## Limitations

- Runtime execution, capabilities, checkpoints and adapters are not available
  in alpha.1.
- Migration handles one explicitly selected scenario and never infers missing
  runtime bindings.
- This release does not claim improved task quality or model independence;
  those claims require the planned controlled pilots.
