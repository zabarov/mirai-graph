# Mirai 2.3.0-alpha.1

Status: experimental prerelease; not a stable or production-write release.

## What It Adds

- typed, deterministic graph query, traversal, projection and diff operations;
- proposal-only graph patches and overlapping cluster organization;
- Program 1.1 bindings to a pinned native operation catalog;
- bounded task delegation with context attenuation, durable receipts, replay,
  evidence requirements and acceptance separate from completion;
- public data-only task registries and bounded TypeScript/Python conformance.
- a committed synthetic organization corpus shared by the TypeScript runtime
  and the independent Python checker.

## Safety Correction

The common JSON admission boundary now rejects secret-like markers and private
paths in property names as well as values. Synthetic regression cases cover
nested keys; no real credentials are included.

## Compatibility

Stable Mirai `2.1.0` remains the recommended production-read baseline.
Mirai `2.2.0-rc.1` remains a gated Autonomic Fabric candidate. This alpha is
additive and does not claim that outstanding 2.2 stable gates are closed.
The `mirai-graph` wrapper remains available for compatibility. The optional
HTTP, PostgreSQL, MySQL and S3 source adapters use the same alpha package
version so npm can resolve prerelease peers; their runtime contracts and
implementation are unchanged.

## Validation

```bash
npm ci
npm run test:mirai-2.3
npm run validate:mirai-2.3-readiness
npm run release:check
```

The prerelease is published only after the exact release commit passes public
Linux, macOS and Windows CI, the independent checker agrees on the bounded
corpora, and security review records no unresolved Critical or High finding.

## Boundaries

- Graph and model output is not authorization.
- Completion is not acceptance.
- Proposals and runtime evidence do not update canonical state automatically.
- The alpha does not authorize production writes or unrestricted autonomy.
- Conformance evidence is not proof of universal correctness or productivity.
