# Mirai 2.2.0-rc.1

Status: unpublished local release candidate; not a stable release.

## Scope

This candidate consolidates the Autonomic Fabric implementation and its
independent-review corrections. It preserves Mirai 2.1 Project Capsule,
Program and Runtime compatibility. The primary package, four optional source
adapters and `mirai-graph` wrapper use the same candidate version.

The release includes read-only Files, Git, HTTP, PostgreSQL, MySQL and
S3-compatible providers; bounded document converters; provenance-bound
knowledge organization; intended/observed process candidates; and reversible
adaptive metadata promotion inside a host-authorized envelope.

## Corrections And Verification

- Reject excessive CSV columns before building row objects.
- Recheck source identity after opening a file and propagate cancellation into
  transport clients; retired database connections are not returned to pools.
- Keep promotion recovery receipted, budgeted and fail-closed.
- Constrain public pilot reports to approved field domains and explicit claims.
- Test allowed reads and forbidden or over-budget requests against controlled
  connector services; missing services fail the integration suite.
- Install the primary package, adapters and compatibility wrapper together in
  clean temporary consumers.

## Remaining Gates

Controlled connector integration, independent AI-assisted source-security
review and four real-source observe/suggest pilots passed their bounded gates.
The full local release suite and six-package installation pass on macOS and
Linux. The independently implemented Python checker passes 23 tests and five
artifact checks on both platforms. These are local arm64 results, not hosted
CI, Windows coverage or approval for production automation.

Local green tests are not a public release. The independent checker must be
published and run against the frozen corpus; Linux, macOS and Windows public
CI must pass at the release revision. Stable metadata, registry publication,
tag and GitHub Release require their own approved release batch.

AI-assisted independent review is not external human peer review. Source
filesystem checks assume an access-controlled source tree; they do not prove
atomic confinement against an actively racing local attacker. Prefer immutable
source snapshots when other principals can modify paths concurrently.

The controlled pilots establish bounded read/proposal integration, not the
semantic correctness of extracted knowledge or comparative scientific benefit.
Neither this candidate nor its evidence authorizes production writes,
unrestricted managed autonomy, self-granted capabilities or canonical learning.
