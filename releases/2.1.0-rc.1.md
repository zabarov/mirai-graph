# Mirai 2.1.0-rc.1

Release type: production-read release candidate

## Summary

Mirai 2.1 consolidates the Mirai 2.0 typed Program and governed Runtime with
graph-native source assimilation, components, multidimensional relation facts,
technology compilation, immutable activation plans and self-describing Project
Capsules.

There was no separately published stable `2.0.0` package. The security-frozen
2.0 core is the execution foundation included in this 2.1 release candidate.
The public product version therefore moves from the 1.4 compatibility line to
2.1 while preserving `mirai-graph` package and CLI compatibility throughout
2.x.

## Included

- typed Mirai Program compilation, deterministic pure execution and replay;
- capability-gated repository/Git reads, sandbox patches, allowlisted tests and
  explicit human approvals;
- durable runs, checkpoints, leases, fencing, receipts, recovery,
  compensation, episodes and sanitized evidence;
- proposal-only Files/Git assimilation with provenance, duplicate and conflict
  classification;
- graph-native components, interfaces, contextual bindings and reified
  multidimensional relation facts;
- reviewable technology drafts and deterministic compilation to Mirai Program;
- immutable activation plans with policy binding, budgets, explanations and
  deterministic parallel joins;
- `mirai/` Project Capsule, deterministic lock, generated START, Agent
  Execution Brief and approval-first legacy migration;
- compatibility wrapper package and CLI aliases for `mirai-graph`.

## Evidence

- complete local `npm run release:check`;
- independent Python conformance checker with public Linux, macOS and Windows
  CI;
- controlled Federation, Larena-shaped and AI Employee pilots without
  production effects;
- owner-authorized isolated AI-assisted security review of exact revision
  `c946d7306099ae03f71cc46f72bcba981e8da03a`;
- public 11-job CI and clean-room matrix on Linux, macOS and Windows;
- public CodeQL at the reviewed revision.

The exact RC package must pass a fresh cross-platform clean-room matrix before
stable promotion.

## Boundaries

- This is not an external human security audit.
- Production-write, live network, secret-changing, financial and public
  publishing adapters are not authorized by this release.
- Graph, Program, runtime state, external state, evidence and proposals remain
  separate authority layers.
- Source assimilation, learning and migration remain proposal/approval-first.
- Controlled and synthetic pilots do not establish comparative effectiveness,
  model independence or broad scientific superiority.
