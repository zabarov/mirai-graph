# Mirai 2.0.0-alpha.2

Release type: development alpha

## Summary

This release adds the deterministic pure reference interpreter, replay and a
portable language conformance corpus. It executes bounded Mirai Programs that
declare only the `pure` effect. Repository, workspace, process and human
approval effects remain unavailable.

## Added

- safe expression evaluator and built-in pure adapters;
- deterministic execution for all Mirai Program control nodes;
- explicit step, depth, iteration, parallel-width and logical-duration budgets;
- deterministic declared-order parallel scheduling and explicit merge policy;
- pure episode and replay contracts;
- public episode, conformance corpus and conformance result schemas;
- a portable corpus covering positive behavior and fail-closed validation;
- `mirai simulate`, `mirai replay` and `mirai conformance run` commands.

## Validation

```bash
npm run test:mirai-alpha2
npm run validate:mirai-conformance
npm run release:check
```

The reference corpus includes 13 cases and repeats deterministic cases up to
100 times. A passing corpus proves agreement with these bounded fixtures only.

## Limitations

- No external adapter or capability grant is executed in this release.
- Await, timeout and retry use logical time rather than wall-clock time.
- Replay re-executes pure programs only; governed effect stubs arrive in
  `2.0.0-alpha.3`.
- Independent Python conformance is required before release candidate status.
- No claim is made about task quality, productivity or model independence.
