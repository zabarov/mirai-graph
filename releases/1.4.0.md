# Mirai Graph 1.4.0

Mirai Graph 1.4.0 adds a domain-neutral executable-technology contract and a
deterministic Course Pack projection.

Scenarios select reusable operations. Compilation includes the complete
prerequisite closure and binds the result to technology and source digests.
Verification fails closed on missing operations, dependency cycles, stale
digests and secret-like fields. Reconciliation classifies changes but never
updates canonical technology automatically.

This is declarative executable technology, not a general program interpreter.
The model has no runtime conditions, bounded loops, issued capabilities or
durable effect execution.

The public `graph.json` manifest contract remains `2.0.0`; Project Technology
activation remains `1.0.0`.
