# Mirai 2.0.0-alpha.3

Release type: development alpha

## Summary

This release adds the first capability-gated and durable Mirai Runtime for a
small reference adapter set. It turns validated Mirai Programs into host-local,
auditable runs without treating graph content as execution authority.

## Added

- host policy decisions and opaque capability grants bound to run, node,
  resource, budget, expiry and Program digest;
- signed host-local approval receipts for sandbox writes and allowlisted test
  commands;
- repository read, Git read/diff, sandbox file patch, allowlisted test and
  human approval adapters;
- durable run records, checkpoints, event log, effect receipts, leases,
  compare-and-swap updates, reconciliation and compensation;
- governed episodes, effect-stub replay and sanitized evidence export;
- public schemas, a synthetic governed-runtime example and negative safety,
  crash and recovery tests;
- CLI commands for approval creation, run, resume, cancel, reconcile, inspect,
  replay and evidence export.

## Validation

```bash
npm run test:mirai-alpha3
npm run test:mirai-property-fuzz
npm run validate:mirai-release-readiness
npm run release:check
```

The alpha.3 suite covers denied and forged capabilities, path and symlink
escape, command injection, environment leakage, crash points, uncertain
receipts, compensation, checkpoint corruption, lease/CAS behavior, replay and
sanitized inspection/export.

The post-alpha engineering gate adds a deterministic bounded property/fuzz
corpus and a machine-readable `2.0.0` readiness report. The report intentionally
remains `blocked`: external review, comparative variance, power analysis,
independent security review, public checker CI and stable metadata are not
complete.

## Boundaries

- runtime execution accepts compiled `.mirai.json`, never authoring YAML;
- network, production, secret-changing, financial and public-publishing
  adapters are excluded;
- an episode or evidence package cannot authorize an effect or update the
  canonical graph;
- exactly-once execution is not claimed;
- private pilot evidence and external scientific validity are not part of this
  alpha release.

The stable compatibility line remains `mirai-graph@1.4.1`.
