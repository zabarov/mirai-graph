# Mirai 2.4.0-alpha.1

Status: experimental prerelease candidate; not published by this batch

Mirai 2.4 introduces Retrieval Fabric as a core extension. It connects the
Hybrid SOT source plane, graph semantics, policies, evidence and Mirai Programs
through a deterministic search plan and evidence-bound answer.

## Included

- `@zabarov/mirai/retrieval` public TypeScript/CommonJS/ESM export;
- Orama-backed local indexes under `.mirai/indexes/`;
- `index plan|build|reconcile|status|verify` and `search` CLI commands;
- exact, BM25, graph and process retrieval, plus explicit optional embeddings;
- Reciprocal Rank Fusion and graph-aware result enrichment;
- source, access, policy, freshness and digest binding;
- federated directory/envelope/result contracts, bounded dispatch, explicit
  timeout handling and digest-bound TTL cache;
- public schemas, fixture, tests and synthetic evaluation API;
- optional `@zabarov/mirai-embedding-local` package.

## Boundaries

- Indexes are disposable projections and never canonical sources.
- Full confidential content is not indexed by default.
- Missing semantic support is reported as degraded mode.
- Search output is evidence, not approval, capability, execution or a graph
  update.
- Federated dispatch primitives do not constitute a production network service.

## Remaining Stable Gates

Independent Python conformance, external security review, controlled pilots,
multilingual benchmark results and clean-room Linux/macOS/Windows verification
must complete before `2.4.0` stable can be proposed.
