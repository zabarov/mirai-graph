# Mirai 2.4.0

Status: stable release candidate; publication is blocked pending exact-commit CI

Mirai 2.4 adds Retrieval Fabric as an additive core extension. It builds
disposable, authorization-bound indexes over Hybrid SOT sources and returns
evidence-bound answers across exact, lexical, optional semantic, graph and
process channels.

## Included

- `@zabarov/mirai/retrieval` contracts and CommonJS/ESM exports;
- Orama-backed local indexes under `.mirai/indexes/`;
- deterministic `index plan|build|reconcile|status|verify` and `search` CLI;
- exact, BM25, graph and process retrieval with explicit degraded mode;
- optional local multilingual embeddings through
  `@zabarov/mirai-embedding-local`;
- Reciprocal Rank Fusion and graph-aware reranking;
- authorization, source, freshness, policy and digest binding;
- bounded federated query envelopes, sanitized result validation and cache;
- public schemas, fixtures, independent conformance receipts and evaluation
  artifacts;
- compatibility with Mirai 2.1 Project Capsules, Program/Runtime contracts,
  Mirai 2.2 source adapters, Mirai 2.3 graph operations and `mirai-graph`.

## Current Evidence

- 121 bilingual controlled queries across five retrieval conditions;
- four public-safe pilot slices: Federation, Larena, AI Employee and
  organization governance;
- independent Python conformance on Linux, macOS and Windows;
- isolated AI-assisted security review with no unresolved critical or high
  finding;
- local full-suite, package and compatibility checks.

The release-readiness record remains
[machine-readable](2.4.0-readiness.json). No release tag or package publication
is permitted while it is blocked.

## Boundaries

- Indexes are removable projections and never canonical sources.
- Retrieval is authorized before indexing and querying.
- Missing semantic support is reported; it is not disguised as semantic
  success.
- Every answer claim must carry evidence; stale or conflicting sources remain
  visible.
- Search does not approve, execute, grant capabilities or update canonical
  graph state.
- Production-write and unrestricted remote federation remain separately
  governed deployment decisions.
- Controlled synthetic evidence does not prove universal retrieval quality or
  real-world organizational effectiveness.
