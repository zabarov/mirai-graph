# Mirai Shadow Differential Minimal

This public-safe fixture compares an accepted two-step preparation and review
technology with an immutable Mirai activation plan. The result must prove
mandatory-step closure, zero scope expansion, no unknown effects and zero
writes. It remains evidence only and cannot authorize activation.

```bash
mirai activation shadow activation-plan.json \
  --baseline accepted-baseline.json \
  --base-dir ../.. \
  --out /tmp/shadow-result.json
```
